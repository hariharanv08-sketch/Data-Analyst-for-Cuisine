Restaurant Data Analysis

Project Overview

This project focuses on analyzing restaurant data to identify useful insights about cuisines, restaurant ratings, restaurant chains, and customer preferences.

The main objective is to explore restaurant datasets, understand trends, and discover meaningful patterns that support data-driven decision-making.

Project Objectives

Cuisine Combination Analysis

- Identify the most common combinations of cuisines.
- Analyze which cuisine combinations tend to receive higher ratings.
- Understand customer preferences for different cuisines.

Data Visualization

- Transform raw data into visual formats.
- Present analytical findings clearly.
- Identify patterns and trends through data visualization.

Restaurant Chain Analysis

- Identify restaurant chains in the dataset.
- Analyze the ratings and popularity of different restaurant chains.
- Compare restaurant performance.

Votes Analysis

- Identify restaurants with the highest and lowest number of votes.
- Analyze the relationship between restaurant votes and ratings.
- Understand customer engagement and restaurant popularity.

Technologies Used

- Python
- Data Analysis
- Data Cleaning
- Exploratory Data Analysis (EDA)
